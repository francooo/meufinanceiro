# Meu Financeiro — Mobile UI Kit editável

Reconstrução estática/editável das 24 telas mobile selecionadas.

## Conteúdo
- `screens/`: 24 páginas HTML independentes, em layout mobile.
- `assets/styles/mobile.css`: tokens, componentes e estilos para mobile.
- `assets/app.js`: conteúdo estático e renderização de cada tela.
- `assets/icons/*.svg`: ícones vetoriais em arquivos independentes e reutilizáveis.
- `assets/screens.json`: manifesto das telas e referências.
- `references/*.jpg`: referências visuais compactadas das imagens selecionadas.
- `index.html`: catálogo para navegar pelas telas.

Extraia o ZIP e abra `index.html` no navegador. O catálogo se adapta à tela; cada tela tem largura mobile e pode ser aberta diretamente.

## Escopo
Os protótipos recriam visualmente componentes e estados como HTML/CSS para edição e reaproveitamento; os ícones foram redesenhados como vetores SVG com traço coerente, não recortados dos pixels. As telas são demonstrativas e não implementam autenticação, persistência, cálculos reais ou conexão com o aplicativo em produção. As imagens originais foram incluídas apenas como referências compactadas.
